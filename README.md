# FastAPI PostgreSQL CRUD

A simple backend project using FastAPI and PostgreSQL with basic CRUD operations.

---

## Features

* Create user
* Get all users
* Update user
* Delete user

---

## Tech Stack

* FastAPI
* PostgreSQL
* SQLAlchemy
* Pydantic

---

## Run Project

```bash
uvicorn main:app --reload
```

---

## API Docs
